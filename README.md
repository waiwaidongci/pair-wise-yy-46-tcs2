# 商业财产保险理赔查勘与定损审核工作台

面向理赔员、专家与主管的商业财产险查勘工作台，覆盖损失科目、修复报价、残值、责任比例、准备金会签、争议项、附件版本、审计时间线与**可撤销的同事故案件并案**。

## 技术栈

Angular + Angular Material + NgRx + Angular Router + HttpClient + RxJS + Angular CLI + TypeScript

## 本地运行

```bash
npm install
npm run start
```

访问 `http://localhost:62046`。

## 核心工作流

- 按案件和损失科目录入查勘事实、照片、报告与保单摘录。
- 调整修复报价时强制填写理由，并保留前后差异。
- 准备金按金额与风险阈值触发多级会签，可退回补件。
- 对比赔付方案、定位争议项、上传附件版本并导出完整审计记录。

## 并案处理（同事故重复建档）

同一场事故常因保单号（如 `…-A` 后缀）、报案地址写法或被保险人简称分别建档，
「并案处理」页把案件、损失科目、附件、准备金和审计接成一条**可撤销事务**：

1. **列候选**：按事故日 + 报案地址核心（道路门牌号归一）+ 保单号（容忍后缀）+
   证据（被保险人名称、科目描述、附件名 2-gram 相似度）自动配对。
2. **冻结快照**：确认前先冻结两案快照（科目/附件/准备金/会签），两案只读。
3. **选主案合并**：
   - 重复科目**合成一项**，双方最新报价作为**金额依据并列**保留；
   - 非重复科目整体带入并标记 `sourceClaimId` 来源引用，附件全部保留并标注来源；
   - 准备金**按主案免赔口径重算**，会签链按新金额重建；
   - 两案原待会签全部置为**已失效待复核**（`invalidatedApprovals`，含来源与原因），
     主案审计时间线追加「并案合并 / 准备金重算 / 会签失效」记录。
4. **并发仲裁**：两人同时确认时**先到者生效**；后到者若主案选择不同，
   其选择与双方操作者被保留为「未决分歧」，看板仍展示先生效的主案，
   可在并案页或审批页处理（接受主案 / 维持分歧转复核）；选择一致只登记并发。
5. **失败回滚**：模拟准备金重算异常等失败时，事务不提交——两案、旧会签按快照恢复，
   附件经数量核对（合并前后不一致直接抛错回滚），失败后可凭原快照重试。
6. **撤销**：已生效并案可一键撤销，两案独立恢复、旧会签重新生效、附件不丢，
   时间线追加撤销记录；未决分歧随之关闭。
7. **重开一致**：案件、会话（候选状态、冻结快照、处理历史、冲突）持久化在
   `localStorage`（`property-claims-merge-v2`），重开页面后候选、处理记录和
   未决冲突仍在，总览、审批页与审计时间线口径一致（准备金不重复计提）。

种子数据内置两对重复建档：`CLM-2026-0918/0919`（同火灾、名称语序+保单后缀差异）
与 `CLM-2026-0927/0928`（同台风、同保单、被保险人简称），可直接演练全流程。
